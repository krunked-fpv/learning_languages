# Wanderling 2.0: The Grand Atlas of Living Tongues (Beginner-to-Fluent A1–C2)

**Wanderling 2.0** is a kid-friendly, tactile, offline-ready Progressive Web App (PWA) game console for learning **16 living languages** from **Beginner (`A1`) to Fluent Mastery (`C1–C2`)** across Latin, Arabic, Cyrillic, Devanagari, Bengali, Simplified Chinese, and Japanese scripts. Young explorers journey alongside **Pip the Polyglot Starling** and regional animal companions (**Mateo**, **Colette**, **Benni**, and **Luca**) across **256 themed cultural units**, **1,792+ adventure map nodes** (plus dynamic Tier Placement Checkpoints), and **2,400+ Living Phrasebook stickers** illustrated with **112 bespoke SVG scenes**.

## 5-Tier CEFR Progression (`A1`–`C2`)

Every one of the 16 courses spans **16 symmetrical cultural units** (**256 units total**). Each unit contains `4` lessons, `1` interactive mini-story, `1` treasure chest, and `1` companion boss gauntlet (**112 standard nodes per language = 1,792 map nodes**, plus on-demand **Tier Placement Checkpoints**) and **150+ unique vocabulary cards per language (`2,400+` total)**:

| CEFR Tier | Rank Title | Units | Scaffolding Mode | Curriculum Focus |
| :--- | :--- | :--- | :--- | :--- |
| **`A1`** | **Sprout** | Units 1–4 | `guided` | Core greetings, cafe treats, animals & nature, family, colors & survival phrases |
| **`A2`** | **Trailblazer** | Units 5–8 | `guided` | Expeditions, music & hobbies, cozy home & clothes, cosmos & everyday conversations |
| **`B1`** | **Storyweaver** | Units 9–11 | `bridge` | Past adventures & storytelling, future dreams & plans, wellness, feelings & empathy |
| **`B2`** | **Wayfinder Diplomat** | Units 12–14 | `bridge` | Science & nature curiosity, festivals, folklore & register contrasts, perspectives & persuasion |
| **`C1+` (`C1_C2`)** | **Polyglot Laureate** | Units 15–16 | `fluent` | Native idiomatic wit & proverbs, multi-clause synthesis & The Grand Polyglot Symposium |

## Core Features & Beginner-to-Fluent Upgrades

- **Adaptive `A1`–`C2` Lesson Mechanics & Free-Recall Mode:**
  - **`guided` (`A1–A2`):** Always-visible phonetic and romanized support alongside tap-hint glosses.
  - **`bridge` (`B1–B2`):** Native-script-first presentation with a 1-tap **Peek Phonetic / Romanized** toggle on lessons, stories, context cloze, and boss gauntlets.
  - **`fluent` (`C1–C2`):** Compact word-bank token chips (`9+` tokens) engineered to fit inside `100dvh` on `375x667` mobile with zero outer scroll.
  - **Context Cloze (`context_cloze`):** Fill-in-the-blank sentence challenges with tap-hint tokens around the blank, 3–4 choices, and a **Nuance / Register Spotlight** (`polite`, `casual`, `idiom`, `connector`, `grammar`).
  - **Keyboard Free-Recall Mode:** Optional typing mode on word-bank and boss turns complete with clickable virtual accent buttons (`LANGUAGE_META[lang].helperAccents`) awarding `+10` bonus XP and `+3` bonus Gems per free-recall solve.
  - **Tier Placement Checkpoints:** Jump straight into `A2`, `B1`, `B2`, or `C1+` from the 5-tier **Adventure Map** ribbon by clearing a 5-exercise placement checkpoint (`unlockProficiencyTier`), unlocking prerequisite nodes cleanly.
- **Multi-Script & Multi-Clause Polyglot Grader (`src/core/grader.ts`):** Normalizes international and multi-clause `B2/C1/C2` punctuation (`¡!¿?.,;:-—"“”`, CJK `。？！，；、・「」『』（）`, Arabic `،؟؛` + tatweel `\u0640`, Indic danda `।॥`), forgives unaccented Latin/Vietnamese/German/Russian free-recall answers with **Accent Spotlight** coaching, strips optional Arabic harakat/tashkeel, collapses spaces between adjacent CJK/Kana characters, accepts romanized answers, and surfaces **Article & Grammar Coaching** across all 16 languages.
- **16-Locale Web Speech (`1.12x` Fluent Mode) & 24 Web Audio SFX (`src/audio/`):** Supports `0.95x` Normal, `0.65x` Slow Turtle, and **`1.12x` Fluent** native cadence (`SpeechSpeed`: `'normal' | 'slow' | 'fluent'`), backed by a `4500ms` hung-utterance watchdog, offline Web Audio sine/triangle marimba syllable cadence (`playPhoneticCadence`), and **24 acoustic Web Audio sound effects** (including `'tier_unlock'`, `'booster_spark'`, `'free_recall_ace'`, `'laureate_fanfare'`, `'equip_prop_pet'`, and `'adult_unlock'`).
- **Grand Emporium — 50 Cosmetics, Props & Pets, Power-Ups & 10 Avatars (`src/core/cosmetics.ts`, `src/components/meta/CompanionShop.tsx`):**
  - **Companion Pedestal Switcher:** Preview `Pip`, `Mateo`, `Colette`, `Benni`, and `Luca` wearing gear across **7 cosmetic slots** (`hat` [9], `glasses` [5], `cape` [4], `aura` [5], handheld `prop` [7], animated mini sidekick `pet` [6], and `theme` [14] — **50 total cosmetics**).

## Getting Started

### Prerequisites

- **Node.js 20+** (tested with Node 22) and **npm**

### Development, Testing & PWA Subpath Verification Commands

```bash
# Install dependencies
npm install

# Start local Vite dev server
npm run dev

# Run the full Vitest suite once (cross-platform, avoids watch mode in PowerShell)
npx vitest run

# Regenerate pure-Node anti-aliased RGBA PNG icons into public/icons/
npm run generate:icons

# Typecheck + build production bundle into dist/ (runs prebuild icon generation)
npm run build

# Verify dist/ PWA manifest, Service Worker, PNG IHDR/CRC32/IDAT binaries,
# relative .woff2 fonts, multi-chunk JS bundles, zero eager adult-mashup-
# modulepreloads in dist/index.html, all 16 cultural landmarks, zero leaked
# external HTTP/HTTPS URLs in JS chunks, and zero Unicode flag emojis
npm run verify:artifacts

# Serve dist/ under /wanderling-subpath/ on an ephemeral or custom port
npm run serve:subpath
node scripts/serve-subpath.mjs --port 4173
```

## PWA & Subpath Hosting Architecture

Wanderling uses strictly relative `./` paths throughout ([`vite.config.ts`](./vite.config.ts) `base: './'`, [`index.html`](./index.html), [`public/manifest.json`](./public/manifest.json), and [`public/sw.js`](./public/sw.js)) so the exact same `dist/` build runs seamlessly at domain root or any nested subpath such as `/<repo-name>/` on GitHub Pages or `/wanderling-subpath/` locally. All 16 base languages and all 7 After-Hours tracks (2 Vol. 1 tracks + 5 Vol. 2 split-emblem mashups) use custom inline SVG emblems (zero Unicode flag emojis `U+1F1E6–U+1F1FF`) and self-hosted `.woff2` fonts with zero external CDN or runtime API requests.

| File | Purpose |
| :--- | :--- |
| [`index.html`](./index.html) | Links `./manifest.json`, `./icons/icon-192.png`, `./icons/apple-touch-icon.png`, sets `#1e1b4b` theme color, documents the Beginner-to-Fluent (`A1`–`C2`) Grand Atlas, and registers `./sw.js` with `{ scope: './' }`. |
| [`public/manifest.json`](./public/manifest.json) | Configures standalone PWA metadata, `#1e1b4b` theme/background colors, `./` start/scope URLs, and both `any` and `maskable` icon entries. |
| [`public/sw.js`](./public/sw.js) | Service Worker (`wanderling-cache-v6`) pre-caching core relative `./` shell & icon assets, purging stale caches via `caches.delete` on `activate`, and serving same-origin GET requests (including the code-split `adult-atlas` and lazy `adult-mashup-*.js` chunks on demand) network-first with cache write-back and offline fallback. |
| [`scripts/generate-pwa-icons.mjs`](./scripts/generate-pwa-icons.mjs) | Zero-dependency Node ESM PNG encoder (`node:zlib` `deflateSync` + IEEE 802.3 CRC32) rendering anti-aliased 8-bit RGBA icons (`192x192`, `512x512`, maskable safe-zone variants, and `180x180` Apple touch icon). |
| [`scripts/verify-build-artifacts.mjs`](./scripts/verify-build-artifacts.mjs) | Automated release gate verifying `dist/index.html` asset links (and confirming zero `<link rel="modulepreload">` tags reference lazy `adult-mashup-` chunks), `dist/manifest.json`, `dist/sw.js`, PNG signatures + `IHDR` + chunk `CRC32` + `IDAT` inflation, relative `./assets/*.woff2` bundled fonts, all 16 cultural landmarks across `dist/assets/*.js` / `*.mjs` chunks, zero leaked external `http://`/`https://` runtime URLs in JS chunks (permitting only W3C XML/DOM namespaces and React's production invariant template), and zero root-relative `/assets/`, external hotlinks, or Unicode flag emojis across `dist/`. |
| [`scripts/serve-subpath.mjs`](./scripts/serve-subpath.mjs) | Zero-dependency Node HTTP preview server mounting `dist/` at `/wanderling-subpath/`, redirecting `/`, and printing `READY http://127.0.0.1:<port>/wanderling-subpath/`. |

## GitHub Pages Deployment

The workflow in [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml) runs automatically on pushes to `main` (and via manual `workflow_dispatch`), executing:

1. `npm ci`
2. `npx vitest run`
3. `npm run build`
4. `node scripts/verify-build-artifacts.mjs`
5. `actions/upload-pages-artifact@v3` & `actions/deploy-pages@v4`

To enable Pages deployment on GitHub, set **Settings -> Pages -> Source** to **GitHub Actions**.
